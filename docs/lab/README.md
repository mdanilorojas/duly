# Lab archive

This folder is the agentic experiment archive. It is not required to run the public demo.

| File | What it is |
|---|---|
| [AGENTIC_EXPERIMENTS_LOG.md](AGENTIC_EXPERIMENTS_LOG.md) | Iteration log for the agentic components. Written while those components were added. |
| [AGENTIC_LOOP_STATE.json](AGENTIC_LOOP_STATE.json) | State file for that loop. Last recorded run is 2026-07-04. The `status` field was left as `running`; nothing in CI reads it. |
| [NORTH_STAR.md](NORTH_STAR.md) | Product catalog and build priority notes from the lab. |
| [VANGUARD_REPORT.md](VANGUARD_REPORT.md) | Weekly research notes from the lab. |
| [references/](references/) | Read-only HTML used as visual inspiration. These files are not apps. |

The public demo, the MCP server, and the local commands are in the repository [README](../../README.md).
